# Titanic Survival Predictor (ML Web App)

An interactive Machine Learning web application designed to predict Titanic passenger survival based on demographic and trip data. 

🌐 **Live Demo:** [Titanic Survival Predictor Web App](https://titanic-survival-predictor-ml-web-app.onrender.com)

## 🚀 Key Features
* **Interactive Web UI:** User-friendly HTML/CSS interface built with Flask.
* **ML Machine Learning Prediction:** Predicts survival probability using trained models (`scaler.pkl` & `svm_model_for_something.sav`).
* **Data-Driven Analysis:** Complete exploratory data analysis documented in Jupyter Notebook (`titanic_project.ipynb`).

## 🛠️ Technologies Used
* **Backend:** Python, Flask
* **Machine Learning & Data Science:** Scikit-Learn, Pandas, NumPy, Jupyter Notebook
* **Frontend:** HTML, CSS (via Flask templates)
* **Deployment:** Render

## 📁 Project Structure
* `app.py`: Main Flask application handling routing and model inference.
* `scaler.pkl`: StandardScaler pickle file for input feature preprocessing.
* `svm_model_for_something.sav`: Saved trained SVM model for survival predictions.
* `titanic_project.ipynb`: Jupyter Notebook containing data preprocessing, EDA, and model training.
* `train.csv`: Dataset used for model training and analysis.
* `requirements.txt`: Project dependencies for seamless deployment.
* `templates/`: HTML interface templates.
